    Download and send it in

      Send it in on GitHub
      1. Download it, then Send it in: the form takes the zip as an attachment (you need a free GitHub account). Every add-on is reviewed before it's added to the catalog.
      2. Or open a pull request yourself: unzip it into addons/, run python pack.py, and include the folder, dist/ and catalog.json. How.
      3. Try it on your own Car Thing first (optional): copy the folder to /var/local/wisp/addons/ over SSH and open Home → Add-ons. How.
